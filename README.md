# Climático — Climate Model Analysis Tools

> **EN:** Code and utilities for analysing CESM experiments related to climate variability and Atlantic Meridional Overturning Circulation (AMOC) collapse.  
> **FR :** Code et outils d'analyse d'expériences CESM portant sur la variabilité climatique et l'effondrement de la circulation méridienne de retournement de l'Atlantique (AMOC).

## 🇬🇧 English

### About
This repository contains code associated with analyses of CESM experiments investigating changes in modes of variability and global climate conditions in response to an AMOC collapse. The repository also includes notebooks, scripts and supporting subpackages.

### Installation
The original project setup instructions use:

```bash
git clone https://github.com/Slymanidiallo/climatico.git
cd climatico
python -m pip install .
```

If installation through the package metadata is not suitable for your environment, the repository also contains a `setup.py` file. Review its dependencies and configuration before installing.

### Repository contents
- `climatico/`, `hosing/`, `isotherm/`: Python package directories.
- `notebooks/`, `examples/`: notebooks and examples.
- `scripts/`, `ncl/`: analysis scripts.
- `install_from_nb.ipynb`: notebook-based installation notes.

### Related publications
- Molina, M. J., Hu, A. & Meehl, G. A., *Response of Global SSTs and ENSO to the Atlantic and Pacific Meridional Overturning Circulations*, Journal of Climate. [Publication](https://journals.ametsoc.org/view/journals/clim/aop/JCLI-D-21-0172.1/JCLI-D-21-0172.1.xml)
- Hu, A. et al. (2021), *The influence of variability in meridional overturning on global ocean circulation*, Journal of Climate. [Publication](https://journals.ametsoc.org/view/journals/clim/aop/JCLI-D-21-0119.1/JCLI-D-21-0119.1.xml)

## 🇫🇷 Français

### Présentation
Ce dépôt rassemble du code associé à l'analyse d'expériences CESM. Les travaux étudient la réponse des modes de variabilité et des conditions climatiques globales à un éventuel effondrement de l'AMOC (circulation méridienne de retournement de l'Atlantique).

### Installation
Les instructions d'installation du projet peuvent être exécutées depuis la racine :

```bash
git clone https://github.com/Slymanidiallo/climatico.git
cd climatico
python -m pip install .
```

Le dépôt contient également un fichier `setup.py`. Vérifiez les dépendances et la configuration avant l'installation dans votre environnement.

### Contenu
- `climatico/`, `hosing/`, `isotherm/` : répertoires de code Python.
- `notebooks/`, `examples/` : notebooks et exemples.
- `scripts/`, `ncl/` : scripts d'analyse.
- `install_from_nb.ipynb` : notes d'installation via notebook.
